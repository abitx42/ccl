# 10 — Evidence Register

Purpose: Stop assumptions turning into "official research". Every fact or figure on the site is classified. This file is the human-readable register; the same rows live in `content/evidence/` as records.

## Status Levels

| Level | Meaning | Can it go on the public site? |
|---|---|---|
| **VERIFIED** | Confirmed against an official source or the project team's own dataset | Yes |
| **RESEARCHER-PROVIDED** | Given by a named team member, not yet independently checked | Yes, labelled, after review |
| **USER-PROVIDED** | Stated by the project owner in conversation/brief | Only after a named verifier confirms |
| **INFERENCE** | Reasoned from other facts | No — until confirmed |
| **PLACEHOLDER** | Temporary text/number | Never in production |
