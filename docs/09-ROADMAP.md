# 09 — Roadmap

Long-term research archive, **zero budget**. Ship a small, correct, maintainable core first; grow it as data, people and funding arrive. Project staffing runs to about 31 Oct 2026 (possibly 30 Nov), so **handover is part of the plan, not an afterthought.**

## Phases

- **Phase 0 — Lock the facts and the rules** (Current)
  - Resolve district list, inventory existing data, setup private GitHub repo and Cloudflare Pages.
- **Phase 1 — Information architecture and design system**
  - Design tokens, typography (Devanagari), core components, accessibility rules.
- **Phase 2 — Home page**
  - Storytelling home page, scroll arrow → data-driven district selector, partners.
- **Phase 3 — District + village engine, pilot district (Palghar)**
  - Templates for District and Village pages; theme system; content validation; build-time visibility/consent filter.
  - End-to-end reference implementation for Palghar.
- **Phase 4 — Research content types**
  - Surveys (aggregated), Challenges → Responses → Outcomes, Biodiversity, Heritage, Media.
  - Pagefind search.
- **Phase 5 — Remaining districts**
  - Scaled by adding folders + themes + verified content.
- **Phase 6 — Research Atlas**
  - Map layers with GeoJSON/PMTiles once clean data exists.
- **Phase 7 — Community visits & research access**
  - Two-stage request and review form.
- **Phase 8 — Marketplace**
  - Enquiry catalogue first; hosted store later.
- **Phase 9 — Hardening, launch, preservation**
  - First Zenodo snapshot with DOI.
- **Phase 10 — Handover and sustainability**
  - Site steward transition, runbooks, editor training.
