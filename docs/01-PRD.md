# 01 — Product Requirements (PRD)

Give the CCL / COOL CRYMB research a public, long-term home: explain the work, publish district- and village-level findings in an engaging way, credit the communities and workers, and let interested outsiders engage responsibly (request access, browse products). It is meant to be a research archive that keeps growing for years, so it is built as a small platform (records with IDs, verification, visibility and consent), not a set of hand-made pages.

## Objectives

1. Communicate the project in under 60 seconds on the home page.
2. Publish each district's research in a structured, comparable way.
3. Give every district its own visual identity while sharing one maintainable codebase.
4. Handle visits and sales through controlled, reviewed channels.
5. Be editable by non-developers, cost nothing to run today, and survive after the project's funded tenure ends.
6. Keep every claim traceable to evidence, and every person/place protected by consent and visibility rules.

## Out of Scope (Today)

- User accounts / logins for the public.
- A full GIS web app (we show curated maps, not an analysis tool).
- Hosting raw survey datasets containing personal information.
- Building our own e-commerce engine.
- Logins for community-only / research-team-only content (needs a backend — funded phase).
- Research Atlas, global search and interactive data explorers before there is clean data (Phases 4–6).

## Priority Matrix

### P0 — Must Ship (MVP & Pilot)
- Home page with intro, project numbers, partners, scroll arrow → district selector
- District selector (cards) driven by data, not hard-coded
- District page template with all sections (see doc 02)
- Per-district theme system (doc 05)
- English + Marathi + Hindi from day one
- Consent gating for all people/photos (doc 08)
- Computed statistics engine

### P1 — Soon After
- Visit request form and admin approval workflow (doc 07)
- Store link-out / enquiry catalogue (doc 06)
- Curated maps (flora/fauna, survey points, vulnerability)
- Downloadable reports (PDF), press kit

### P2 — Later
- Site search, timeline of field visits, cross-district comparison, newsletter, full store

## Constraints

- **Budget:** Zero. Free tools only, with upgrade triggers defined in doc 03.
- **Time:** RA posts run 20 Jul – 31 Oct 2026 (extendable to 30 Nov). MVP must be maintainable post-funding.
- **Team:** Small, mostly non-developers.
- **Devices:** Mobile-first; mid-range Android on patchy 4G.
- **Rules:** Content from verified data only; no fabricated numbers or names.
